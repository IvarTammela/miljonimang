# Lõppdemo kirjeldus

## Demo voog

1. Käivita rakendus käsuga `php -S localhost:8000 -t public`.
2. Ava brauseris `http://localhost:8000`.
3. Näita, et avalehel kuvatakse mitu `input/` kausta ülesannet.
4. Sisesta mängija nimi.
5. Vali ülesanne, näiteks `001 - JavaScripti kalkulaator`.
6. Alusta mängu ning vasta esimesele küsimusele.
7. Kasuta vähemalt ühte õlekõrt.
8. Näita vale vastuse korral lõpptulemust.
9. Näita, et tulemus lisatakse edetabelisse.
10. Selgita, et GitHub Pages versioon kasutab eelgenereeritud küsimustepanka ja PHP versioon saab kasutada OpenAI ühendust.
