# Definition of Done

Funktsionaalsus loetakse valmis, kui:

- kasutajalugu on seotud konkreetse nähtava funktsiooniga;
- vastuvõtutingimused on käsitsi läbi testitud;
- rakendus töötab ilma PHP vigadeta;
- kasutaja saab veateate või selge tulemuse;
- kood on jaotatud loogilisteks osadeks;
- README või dokumentatsioon kirjeldab kasutamist ja piiranguid.
