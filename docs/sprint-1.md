# Sprint 1

## Eesmärk

Luua arvestatav MVP, kus õppija saab valida ülesande, genereerida küsimused, mängida 15 küsimusega mängu ja näha tulemust.

## Valitud järjekord

Esmalt valmis failide lugemine ja ülesannete valik, sest kogu mäng sõltub sellest kontekstist. Seejärel valmis küsimuste generaator koos fallbackiga, et rakendus töötaks ka ilma API võtmeta. Pärast seda valmis mänguloogika, õlekõrred ja dokumentatsioon.

## Töövoog

- Backlog: tulemuste ajalugu, õpetaja vaade, veebist ülesande lisamine.
- Todo: käsitsi testimine ja demo läbimäng.
- In progress: MVP funktsioonide ühendamine.
- Review/Test: mänguvoog, fallback ja õlekõrred.
- Done: ülesannete valik, failide lugemine, küsimused, mänguvaade, README ja protsessi dokumendid.
