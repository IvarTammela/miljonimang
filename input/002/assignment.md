# JSON-andmete kuvamine

Loo veebileht, mis loeb etteantud JSON-andmed ja kuvab toodete nimekirja kasutajale.

## Nõuded

- Andmed asuvad failis `data.json`.
- Iga toote kohta kuvatakse nimi, hind ja kategooria.
- Kui andmeid ei ole, kuvatakse tühi olek.
- Kood peab olema jaotatud väikesteks funktsioonideks.

## Hindamiskriteeriumid

- JSON andmed on korrektselt loetud.
- DOM-i uuendamine on arusaadav.
- Puuduvate või tühjade andmete juhtum on käsitletud.
