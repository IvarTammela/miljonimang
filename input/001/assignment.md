# JavaScripti kalkulaator

Loo lihtne veebileht, kus kasutaja saab sisestada kaks arvu ja valida tehte: liitmine, lahutamine, korrutamine või jagamine.

## Nõuded

- Lehel on kaks arvu sisestamise välja.
- Lehel on tehte valik.
- Nupu vajutamisel arvutatakse tulemus JavaScriptiga.
- Jagamisel nulliga kuvatakse kasutajale arusaadav veateade.
- Tulemus kuvatakse samal lehel.

## Hindamiskriteeriumid

- HTML struktuur on loogiline.
- JavaScript loeb kasutaja sisendi ja teisendab selle arvuks.
- Lahendus kontrollib vigaseid sisendeid.
- Kasutajale kuvatakse tulemus või veateade.
